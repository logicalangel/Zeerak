{{else if eq $kind "nat"}}
Port forwards (DNAT)

One rule per line: [proto] <ext_port> <to_addr>[:<to_port>] [iif=<iface>] [from=<cidr>]. Default proto is tcp; to_port defaults to ext_port. IPv4 destinations only.

Masquerade (SNAT)

One rule per line: <oif> [<source-cidr>]. Masquerades every packet leaving oif; add a CIDR to scope it (e.g. only the LAN).

Compiles into ip zeerak-nat with prerouting (priority -100) + postrouting (priority 100).

{{else if eq $kind "marks"}}
Policy-routing marks

One rule per line: <name> set=<value> [proto=tcp|udp] [dport=<n>] [oif=<iface>] [daddr=<cidr>]. set accepts decimal or 0x-hex.

Compiles into inet zeerak-marks, output chain (type route, priority -150). Use ip rule fwmark <value> lookup <table> in your routing layer to act on these marks.

Attach kernel conntrack helpers at their canonical ports. Only enable the ones you actually use — helpers parse application traffic and have historically been a source of CVEs.

Compiles into inet zeerak-ct, prerouting priority -200, so helpers attach before any filter decisions in zeerak-presets.
